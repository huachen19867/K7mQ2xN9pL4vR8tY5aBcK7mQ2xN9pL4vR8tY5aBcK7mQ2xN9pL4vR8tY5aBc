新增一条演示假条

在飞书表格中填写完整假条：联系人、事由、课程、凭证，以及各级意见、姓名、日期和签字图片。确认可公开后勾选发布。

打开请假记录表↗ 前往 GitHub 手动立即发布↗

发布前只需完成三步

  1. 新增一行在飞书表格中只添加这条演示假条。
  2. 填写记录填写假条详情与各级意见，凭证和现有签字图直接上传附件列。
  3. 勾选发布勾选“发布”后等待同步，或手动运行 GitHub 发布。

请留意：未勾选“发布”的记录不会公开。自动同步约每 10 分钟运行一次，GitHub 调度可能延迟；出错时会保留现有公开快照。状态为“已批准”的记录会归入前台“已完成”，卡片使用原有绿色“已完成”印章。飞书与 GitHub 操作权限由各自的账号登录和权限控制。

这里只管理静态演示内容。新增记录不会提交到学校系统，也不会发起学校审批。
